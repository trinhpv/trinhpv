1.1. CÁC DẠNG BÀI STRING CƠ BẢN
────────────────────────────────────────────────────────────────────────────────

[A] Xử lý chuỗi cơ bản

[D] Substring & Subsequence

    Template cơ bản:
    ┌─────────────────────────────────────────────────────┐
    │  left = 0                                           │

    │      # Cập nhật kết quả                            │

    • Subarray Sum Equals K

    Công thức:

    │  prefix[0] = 0                                      │
    │  prefix[i] = prefix[i-1] + arr[i-1]                │

────────────────────────────────────────────────────────────────────────────────
2.1. KIẾN THỨC NỀN TẢNG
────────────────────────────────────────────────────────────────────────────────

[A] Biểu diễn đồ thị
    • Adjacency List (danh sách kề) ← phổ biến nhất
    • Adjacency Matrix (ma trận kề)
    • Edge List (danh sách cạnh)
    • Implicit Graph (lưới 2D, trạng thái)

    Template Adjacency List:
    ┌─────────────────────────────────────────────────────┐
    │  graph = defaultdict(list)                          │
    │  for u, v in edges:                                 │
    │      graph[u].append(v)                             │
    │      graph[v].append(u)  # nếu vô hướng           │
    └─────────────────────────────────────────────────────┘

[B] Template DFS (Depth-First Search - Tìm kiếm theo chiều sâu)
    
    Đệ quy:
    ┌─────────────────────────────────────────────────────┐
    │  def dfs(node, visited):                            │
    │      visited.add(node)                              │
    │      for neighbor in graph[node]:                   │
    │          if neighbor not in visited:                 │
    │              dfs(neighbor, visited)                  │
    └─────────────────────────────────────────────────────┘

    Dùng Stack:
    ┌─────────────────────────────────────────────────────┐
    │  stack = [start]                                    │
    │  visited = set()                                    │
    │  while stack:                                       │
    │      node = stack.pop()                             │
    │      if node in visited: continue                   │
    │      visited.add(node)                              │
    │      for neighbor in graph[node]:                   │
    │          if neighbor not in visited:                 │
    │              stack.append(neighbor)                  │
    └─────────────────────────────────────────────────────┘

[C] Template BFS (Breadth-First Search - Tìm kiếm theo chiều rộng)

    ┌─────────────────────────────────────────────────────┐
    │  from collections import deque                      │
    │  queue = deque([start])                             │
    │  visited = {start}                                  │
    │  level = 0                                          │
    │  while queue:                                       │
    │      size = len(queue)                              │
    │      for _ in range(size):                          │
    │          node = queue.popleft()                     │
    │          for neighbor in graph[node]:               │
    │              if neighbor not in visited:             │
    │                  visited.add(neighbor)               │
    │                  queue.append(neighbor)              │
    │      level += 1                                     │
    └─────────────────────────────────────────────────────┘

2.2. CÁC DẠNG BÀI DFS
────────────────────────────────────────────────────────────────────────────────

[A] DFS trên cây (Tree DFS)
    • Duyệt cây: Preorder, Inorder, Postorder
    • Tính chiều cao / độ sâu
    • Đường kính cây (Diameter of Binary Tree)
    • Lowest Common Ancestor - LCA (Tổ tiên chung gần nhất)
    • Path Sum (tìm đường đi có tổng = target)
    • Serialize và Deserialize cây
    • Kiểm tra cây đối xứng (Symmetric Tree)
    • Balanced Binary Tree

    Ví dụ bài tập:
    - Maximum Depth of Binary Tree
    - Path Sum I, II, III
    - Binary Tree Maximum Path Sum
    - Diameter of Binary Tree
    - Lowest Common Ancestor of a Binary Tree
    - Validate Binary Search Tree - BST (Cây tìm kiếm nhị phân)
    - Flatten Binary Tree to Linked List

[B] DFS trên đồ thị (Graph DFS)
    • Đếm số thành phần liên thông (Connected Components)
    • Phát hiện chu trình (Cycle Detection)
        - Đồ thị vô hướng: dùng parent tracking
        - Đồ thị có hướng: dùng 3 màu (white/gray/black)
    • Topological Sort (Sắp xếp tô-pô - sắp xếp thứ tự phụ thuộc trong đồ thị có hướng không chu trình DAG - Directed Acyclic Graph)
    • Tìm cầu và khớp (Bridges - cạnh cầu & Articulation Points - đỉnh khớp) → Tarjan (Thuật toán Tarjan)
    • Strongly Connected Components - SCC (Thành phần liên thông mạnh) → Kosaraju / Tarjan
    • Bipartite Check (kiểm tra đồ thị 2 phía)

    Ví dụ bài tập:
    - Number of Connected Components
    - Course Schedule I, II (Cycle Detection + Topo Sort)
    - Detect Cycle in Directed/Undirected Graph
    - Critical Connections in a Network (Bridges)
    - Is Graph Bipartite?
    - Alien Dictionary (Topo Sort)

[C] DFS trên lưới 2D (Grid DFS)
    • Đếm đảo (Number of Islands)
    • Diện tích đảo lớn nhất
    • Flood Fill
    • Surrounded Regions
    • Đường đi trong mê cung

    Di chuyển 4 hướng:
    ┌─────────────────────────────────────────────────────┐
    │  directions = [(0,1), (0,-1), (1,0), (-1,0)]       │
    │  for dx, dy in directions:                          │
    │      nx, ny = x + dx, y + dy                       │
    │      if 0 <= nx < rows and 0 <= ny < cols:         │
    │          # xử lý ô (nx, ny)                        │
    └─────────────────────────────────────────────────────┘

    Ví dụ bài tập:
    - Number of Islands
    - Max Area of Island
    - Flood Fill
    - Surrounded Regions
    - Pacific Atlantic Water Flow
    - Word Search

[D] Backtracking (Quay lui) - mở rộng DFS
    • Sinh tổ hợp (Combinations)
    • Sinh hoán vị (Permutations)
    • Tập con (Subsets)
    • N-Queens Problem
    • Sudoku Solver
    • Word Search

    Template Backtracking:
    ┌─────────────────────────────────────────────────────┐
    │  def backtrack(path, choices):                      │
    │      if (đạt mục tiêu):                            │
    │          result.append(path[:])                     │
    │          return                                     │
    │      for choice in choices:                         │
    │          if (hợp lệ):                              │
    │              path.append(choice)                    │
    │              backtrack(path, new_choices)            │
    │              path.pop()  # quay lui                │
    └─────────────────────────────────────────────────────┘

    Ví dụ bài tập:
    - Subsets I, II
    - Permutations I, II
    - Combinations
    - Combination Sum I, II, III
    - N-Queens
    - Palindrome Partitioning

2.3. CÁC DẠNG BÀI BFS
────────────────────────────────────────────────────────────────────────────────

[A] BFS tìm đường ngắn nhất (Shortest Path)

    • Đường ngắn nhất trong lưới 2D
    • Shortest Path with Obstacles Elimination

    Ví dụ bài tập:
    - Shortest Path in Binary Matrix
    - Shortest Bridge
    - 01 Matrix (Multi-source BFS)
    - Rotting Oranges (Multi-source BFS)
    - Jump Game (BFS approach)
    - Word Ladder

[B] BFS theo tầng (Level-order)
    • Duyệt cây theo tầng (Level Order Traversal)
    • Zigzag Level Order
    • Right Side View
    • Minimum Depth of Binary Tree

    Ví dụ bài tập:
    - Binary Tree Level Order Traversal
    - Binary Tree Zigzag Level Order Traversal
    - Binary Tree Right Side View
    - Average of Levels in Binary Tree

[C] BFS trên trạng thái (State-space BFS)
    • Mỗi "node" là một trạng thái (state)
    • Tìm số bước tối thiểu để đạt trạng thái đích
    • Sliding Puzzle
    • Open the Lock

    Ví dụ bài tập:
    - Open the Lock
    - Sliding Puzzle
    - Minimum Genetic Mutation
    - Word Ladder I, II

[D] 0-1 BFS (BFS với trọng số 0 và 1)
    • Dùng deque thay vì queue thông thường
    • Cạnh trọng số 0: thêm vào đầu deque
    • Cạnh trọng số 1: thêm vào cuối deque

    Template:
    ┌─────────────────────────────────────────────────────┐
    │  deq = deque([(0, start)])  # (cost, node)         │
    │  dist = {start: 0}                                  │
    │  while deq:                                         │
    │      cost, node = deq.popleft()                    │
    │      for w, neighbor in graph[node]:               │
    │          new_cost = cost + w                        │
    │          if new_cost < dist.get(neighbor, inf):     │
    │              dist[neighbor] = new_cost              │
    │              if w == 0:                              │
    │                  deq.appendleft((new_cost, nei))   │
    │              else:                                   │
    │                  deq.append((new_cost, nei))        │
    └─────────────────────────────────────────────────────┘

PHẦN 3: DYNAMIC PROGRAMMING - DP (Quy hoạch động) (Câu 4)
================================================================================

────────────────────────────────────────────────────────────────────────────────
3.1. PHƯƠNG PHÁP TIẾP CẬN DP (Dynamic Programming - Quy hoạch động)
────────────────────────────────────────────────────────────────────────────────

Bước 1: Xác định TRẠNG THÁI (state)
    → dp[i] đại diện cho cái gì?
    → Có cần thêm chiều không? dp[i][j]?

Bước 2: Xác định CÔNG THỨC CHUYỂN TRẠNG THÁI (transition)
    → dp[i] được tính từ những trạng thái nào trước đó?

Bước 3: Xác định TRẠNG THÁI GỐC (base case)
    → dp[0] = ? dp[1] = ?

Bước 4: Xác định THỨ TỰ TÍNH TOÁN
    → Bottom-up / tabulation (tính từ dưới lên - điền bảng) hay Top-down / memoization (tính từ trên xuống - ghi nhớ kết quả)?

Bước 5: TỐI ƯU không gian nếu có thể
    → Nếu dp[i] chỉ phụ thuộc dp[i-1] → dùng biến thay mảng

────────────────────────────────────────────────────────────────────────────────
3.2. CÁC DẠNG DP KINH ĐIỂN
────────────────────────────────────────────────────────────────────────────────

[A] DP 1 chiều cơ bản (1D DP - One-Dimensional Dynamic Programming)
    • Fibonacci, Climbing Stairs
    • House Robber I, II
    • Decode Ways
    • Maximum Subarray (Kadane's Algorithm)
    • Jump Game I, II
    • Coin Change (số đồng xu tối thiểu)
    • Word Break

    Mẫu chung:
    ┌─────────────────────────────────────────────────────┐
    │  dp[i] = f(dp[i-1], dp[i-2], ...)                  │
    └─────────────────────────────────────────────────────┘

    Ví dụ - House Robber:
    dp[i] = max(dp[i-1], dp[i-2] + nums[i])

[B] DP 2 chiều (2D DP)
    • Unique Paths I, II
    • Minimum Path Sum
    • Edit Distance
    • Longest Common Subsequence - LCS (Dãy con chung dài nhất)
    • Longest Palindromic Subsequence
    • Regular Expression Matching
    • Wildcard Matching
    • Interleaving String

    Mẫu chung:
    ┌─────────────────────────────────────────────────────┐
    │  dp[i][j] = f(dp[i-1][j], dp[i][j-1], ...)        │
    └─────────────────────────────────────────────────────┘

    Ví dụ - Edit Distance:
    dp[i][j] = dp[i-1][j-1]                   nếu s[i] == t[j]
    dp[i][j] = 1 + min(dp[i-1][j],            insert
                       dp[i][j-1],             delete  
                       dp[i-1][j-1])           replace

[C] Knapsack (Bài toán ba lô - Bài toán cái túi)
    
    ★ 0/1 Knapsack (mỗi vật chọn hoặc không):
    ┌─────────────────────────────────────────────────────┐
    │  dp[i][w] = max(dp[i-1][w],                        │
    │                 dp[i-1][w - weight[i]] + value[i])  │
    └─────────────────────────────────────────────────────┘

    ★ Unbounded Knapsack (chọn không giới hạn):
    ┌─────────────────────────────────────────────────────┐
    │  dp[w] = max(dp[w], dp[w - weight[i]] + value[i])  │
    │  (duyệt w từ weight[i] → W)                        │
    └─────────────────────────────────────────────────────┘

    ★ Subset Sum / Partition:
    dp[i][s] = dp[i-1][s] OR dp[i-1][s - nums[i]]

    Ví dụ bài tập:
    - 0/1 Knapsack
    - Partition Equal Subset Sum
    - Target Sum
    - Coin Change (Unbounded Knapsack)
    - Coin Change 2 (đếm số cách)
    - Ones and Zeroes

[D] DP trên chuỗi (String DP)
    • Longest Palindromic Subsequence
    • Longest Common Subsequence
    • Edit Distance
    • Distinct Subsequences
    • Palindrome Partitioning II (min cuts)
    • Word Break I, II
    • Regular Expression Matching

[E] DP khoảng (Interval DP)
    • Burst Balloons
    • Matrix Chain Multiplication
    • Palindrome Partitioning
    • Stone Game
    • Minimum Cost to Merge Stones

    Mẫu chung:
    ┌─────────────────────────────────────────────────────┐
    │  for length in range(2, n+1):      # độ dài khoảng│
    │      for i in range(n - length + 1):               │
    │          j = i + length - 1                         │
    │          for k in range(i, j):     # điểm chia    │
    │              dp[i][j] = min/max(dp[i][k] + ...)    │
    └─────────────────────────────────────────────────────┘

[F] DP trên cây (Tree DP)
    • House Robber III
    • Binary Tree Maximum Path Sum
    • Diameter of Binary Tree
    • Longest Path in a Tree
    • Distribution of resources on tree

    Mẫu chung:
    ┌─────────────────────────────────────────────────────┐
    │  def dfs(node):                                     │
    │      if not node: return base_case                  │
    │      left = dfs(node.left)                          │
    │      right = dfs(node.right)                        │
    │      # Tính dp cho node dựa trên left, right       │
    │      return result                                  │
    └─────────────────────────────────────────────────────┘

[G] DP Bitmask (DP trên tập con - bitmask)
    • Travelling Salesman Problem - TSP (Bài toán người bán hàng - tìm đường đi ngắn nhất qua tất cả các thành phố)
    • Assignment Problem
    • Shortest Hamiltonian Path (Đường đi Hamilton ngắn nhất - đường đi qua mọi đỉnh đúng 1 lần)
    • Partition to K Equal Sum Subsets

    Mẫu chung:
    ┌─────────────────────────────────────────────────────┐
    │  dp[mask][i] = chi phí tối thiểu khi đã thăm các  │
    │                đỉnh trong mask, kết thúc tại i     │
    │                                                     │
    │  for mask in range(1 << n):                        │
    │      for i in range(n):                             │
    │          if mask & (1 << i):                        │
    │              for j in range(n):                     │
    │                  if not (mask & (1 << j)):          │
    │                      new_mask = mask | (1 << j)     │
    │                      dp[new_mask][j] = min(...)     │
    └─────────────────────────────────────────────────────┘

[H] DP tối ưu với các cấu trúc dữ liệu
    • Longest Increasing Subsequence - LIS (Dãy con tăng dài nhất) + Binary Search (Tìm kiếm nhị phân) → O(n log n)
    • DP + Monotone Stack (Ngăn xếp đơn điệu)
    • DP + Segment Tree (Cây phân đoạn - cây đoạn)
    • Convex Hull Trick (Kỹ thuật bao lồi - tối ưu DP dạng tuyến tính)

    Ví dụ - LIS (Longest Increasing Subsequence - Dãy con tăng dài nhất) O(n log n):
    ┌─────────────────────────────────────────────────────┐
    │  tails = []                                         │
    │  for num in nums:                                   │
    │      pos = bisect_left(tails, num)                  │
    │      if pos == len(tails):                          │
    │          tails.append(num)                           │
    │      else:                                           │
    │          tails[pos] = num                            │
    │  return len(tails)                                   │
    └─────────────────────────────────────────────────────┘

────────────────────────────────────────────────────────────────────────────────
3.3. CÁC MẸO QUAN TRỌNG KHI LÀM DP
────────────────────────────────────────────────────────────────────────────────

1. Luôn bắt đầu bằng cách viết đệ quy (top-down) trước
   → Dễ nghĩ hơn, dễ debug hơn
   → Thêm memoization (ghi nhớ kết quả, dùng @lru_cache hoặc dict)
   → Chuyển sang bottom-up nếu cần tối ưu

2. Vẽ bảng DP ra giấy với ví dụ nhỏ
   → Giúp phát hiện pattern chuyển trạng thái

3. Chú ý base case
   → Nhiều bài sai vì base case thiếu hoặc sai

4. Tối ưu không gian
   → Nếu dp[i] chỉ cần dp[i-1]: dùng 2 biến hoặc 2 hàng
   → Giảm O(n²) space → O(n)

5. Nhận diện bài DP:
   → "Tìm số cách..." → DP đếm
   → "Tìm giá trị lớn nhất/nhỏ nhất..." → DP tối ưu
   → "Có thể hay không..." → DP boolean
   → Có tính chất overlapping subproblems (bài toán con trùng lặp) + optimal substructure (cấu trúc con tối ưu)
